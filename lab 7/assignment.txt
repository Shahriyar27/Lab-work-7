2. Task Description
 
Imagine that you are developing an online gaming store. The store sells gaming laptops, 
keyboards, mice, and headsets.
 
Your application must allow users to:
 
1.
 
View all gaming products.
 
2.
 
Add new products.
 
3.
 
Edit product information.
 
4.
 
Delete products.
 
5.
 
Place orders and calculate the total price.
 
6.
 
View orders.
 
You must implement the following design patterns:
 
Facade Pattern:
 
Simplify the order creation process. One method must coordinate product 
validation, price calculation, and saving the order.
 
Proxy Pattern:
 
Restrict product management operations to administrators. Customers can 
view products and place orders but cannot add, edit, or delete products.

import sqlite3
 
 
DB_NAME = "store.db"
 
 
 
def connect():
 
    
conn = sqlite3.connect(DB_NAME)
 
    
conn.row_factory = sqlite3.Row
 
    
conn.execute("PRAGMA foreign_keys = ON")
 
    
return conn
 
 
 
def init_db():
 
    
conn = connect()

# PROXY PATTERN
 
class ProductProxy:
 
    
def __init__(self, role):
 
        
self.role = role
 
 
    
def check_permission(self, action):
 
        
if action == "view":
 
            
return True
 
 
        
if self.role != "admin":
 
            
raise PermissionError(
 
                
"Only administrators can manage products."
 
            
)
 
 
        
return True

class OrderFacade:
 
    
def place_order(self, customer_name, product_id, quantity):
 
        
if not customer_name.strip():
 
            
raise ValueError("Customer name is required.")
 
 
        
if quantity < 1:
 
            
raise ValueError("Quantity must be at least 1.")
